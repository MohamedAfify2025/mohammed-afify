# Mohammed Afify — Portfolio Website

نسخة أولية احترافية Responsive مبنية على الهيكل الذي اتفقنا عليه:
- الصفحة الرئيسية / Hero
- عني
- الأكاديمية والكورسات
- Odoo Solutions
- المشاريع والحلول
- Data Analysis
- الشهادات
- التواصل

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح.

## قبل النشر
استبدل بيانات التواصل الوهمية في `index.html`:
- البريد: `info@example.com`
- WhatsApp وLinkedIn

ثم أضف روابط الصفحات الأصلية للكورسات والمشاريع من Google Sites.

الصورة الرئيسية المستخدمة هي الصورة التي أرسلها المستخدم، داخل:
